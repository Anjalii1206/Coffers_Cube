## 📂 Project Structure

### 🖥️ Frontend
- Developed using **React.js** with a modern UI.
- Users can browse Food Items, view Menu items, Add to cart, and Proceed to checkout.
- Responsive design for both **mobile and desktop**.

### 🔧 Backend
- Built with **Node.js** and **Express.js**.
- Uses **MongoDB** for storing user, order, and product details.
- Handles **authentication, order processing, and API requests**.

### 🛠️ Admin Panel
- Built with **React.js** and **Express.js**.
- Allows restaurant owners to **add, edit, or delete menu items**.
- Displays **Current status of Order and Order details** for better management.

## 📥 How to Clone or Fork this Project

1. **Clone the repository**
   ```sh
   git clone https://github.com/Anjalii1206/Coffers_Cube.git
   ```

2. **Navigate to the project folder**
   ```sh
   cd food-delivery-website
   ```

3. **Install dependencies for both frontend and backend:**
   ```sh
   cd frontend
   npm install
   cd ../backend
   npm install
   ```

4. **Set up environment variables in `.env` files for frontend and backend:**
   - MongoDB connection string
   - Stripe API keys

5. **Run the project**
   ```sh
   # Start the backend
   cd backend
   npm start
   ```
   
   ```sh
   # Open a new terminal and start the frontend
   cd frontend
   npm start
   ```

## 🌟 Features

✅ **User-Friendly UI**: Responsive and easy to navigate.  
✅ **Cart System**: Add items to the cart and update quantities.  
✅ **Secure Payments**: Integrated with Razorpay for safe transactions.  
✅ **Order Management**: Users can track orders, and admins can manage them.  
✅ **Authentication**: Secure login and sign-up system.  
✅ **Admin Dashboard**: Add, edit, and remove food items from the menu.
